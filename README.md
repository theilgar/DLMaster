# DLLMasterBot

YouTube və Spotify playlistlərindən mahnı yükləmək üçün Telegram botu.

## 📋 Xüsusiyyətlər

- YouTube playlist yükləmə
- Spotify playlist yükləmə (YouTube vasitəsilə)
- Fərdi mahnı axtarışı (`/music` komandası)
- İstifadəçi yükləmə tarixçəsi (`/my_songs`)
- Qrup dəstəyi (admin hüquqları tələb olunur)
